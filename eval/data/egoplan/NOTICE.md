# EgoPlan data notice
This directory ships only identifiers (sample ids, relative image paths) and sha256 checksums for the EgoPlan-Bench validation
subset we evaluate on. It contains no video frames, no questions and no answers.
The data themselves come from lmms-lab/EgoPlan-Bench (derived from EgoPlan-Bench, Chen et al., arXiv 2312.06722), whose videos
originate from EPIC-KITCHENS-100 (CC BY-NC 4.0) and Ego4D (Ego4D license agreement). Obtain them from the official sources
(`benchmarks/egoplan/download.sh`) and comply with those terms. Checksums and id lists in this directory: Apache-2.0.
